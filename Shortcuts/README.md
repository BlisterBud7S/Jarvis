# Jarvis Shortcuts

These iOS Shortcuts extend what Jarvis can control on your iPad.
Import them into the Shortcuts app to enable full device control.

## How to Create the Required Shortcuts

### 1. Open App (Required)
1. Open Shortcuts app
2. Create new shortcut named "Open App"
3. Add "Shortcut Input" → Set to receive Text
4. Add "Open App" action → Set app to "Shortcut Input"

### 2. Set Volume
1. Create shortcut named "Set Volume"
2. Add "Shortcut Input" → receive Text
3. Add "Set Volume" action → set to Shortcut Input

### 3. Toggle WiFi
1. Create shortcut named "Toggle WiFi"
2. Add "Set Wi-Fi" action → Toggle

### 4. Toggle Bluetooth
1. Create shortcut named "Toggle Bluetooth"
2. Add "Set Bluetooth" action → Toggle

### 5. Toggle Dark Mode
1. Create shortcut named "Toggle Dark Mode"
2. Add "Set Appearance" action → Toggle

### 6. Toggle Low Power
1. Create shortcut named "Toggle Low Power"
2. Add "Set Low Power Mode" action → Toggle

### 7. Set Timer
1. Create shortcut named "Set Timer"
2. Add "Shortcut Input" → receive Text
3. Add "Start Timer" → Duration: Shortcut Input minutes

### 8. Take Photo
1. Create shortcut named "Take Photo"
2. Add "Take Photo" action
3. Add "Save to Photo Album" action

### 9. Speak Text
1. Create shortcut named "Speak Text"
2. Add "Shortcut Input" → receive Text
3. Add "Speak Text" action → Text: Shortcut Input

### 10. Create Note
1. Create shortcut named "Create Note"
2. Add "Shortcut Input" → receive Text
3. Add "Create Note" → Body: Shortcut Input

### 11. Create Reminder
1. Create shortcut named "Create Reminder"
2. Add "Shortcut Input" → receive Text
3. Add "Add New Reminder" → Title: Shortcut Input

### 12. Play Playlist
1. Create shortcut named "Play Playlist"
2. Add "Shortcut Input" → receive Text
3. Add "Find Music" → filter by Playlist Name is Shortcut Input
4. Add "Play Music" action

## Tips
- Name shortcuts EXACTLY as listed above — Jarvis uses these names to call them
- Test each shortcut manually before using with Jarvis
- You can create custom shortcuts and tell Jarvis to run them by name
